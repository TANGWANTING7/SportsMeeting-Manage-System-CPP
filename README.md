# 🏅 校际运动会管理系统 (C++ 实现)

这是一个基于 C++ 开发的命令行界面 (CLI) 校际运动会信息与赛程管理系统。主要用于支持多所学校参与的赛事流程，提供从运动员报名、比赛成绩录入到总分排行统计的完整闭环功能，同时采用本地物理文件进行数据持久化存储。

## ✨ 项目特点 (Features)

- **严格的报名规则校验**：程序内建校验逻辑，严格控制如“每个学校单项参赛人数不超过4人”、“每名运动员最多只能参加3项单项比赛”等规则。
- **智能化动态计分系统**：根据项目的参赛人数自动适配比赛积分规则（例如：大于6人取前五名积分 7,5,3,2,1；不超过6人取前三名积分 5,3,2），并支持团体赛自动加倍或自定义名次权值。
- **本地物理层数据持久化**：系统运行中产生的所有核心数据（例如学校资料、项目信息、运动员报名信息与成绩）均会格式化存储于独立的 `data/` 目录下，彻底告别单次运行数据即丢失的问题。
- **标准 C++ 现代化工程结构**：摈弃单文件数千行的意大利面条式代码。使用标准的 `src` / `include` 分层模块化设计（数据录入模块、赛事模块、查询模块分离），且配置好了标准的 `CMakeLists.txt` 便于跨平台移植与调试。

## 🚀 核心功能模块 (Functions)

### 1. 📝 信息录入与报名模块
- 初始化赛事基本参数：参赛学校总数、男/女子项目总数。
- 录入参赛学校详细信息。
- 设置比赛项目细节及积分机制。
- 按照学校为单位，对参赛运动员进行合规性报名登记。

### 2. 🏁 赛程与成绩管理模块
- **项目赛前检录**：确保参赛人员的核对。
- **获奖名次录入**：比赛结束后，依名次引导录入选手成绩。
- **自动计分挂统**：依据设定好的赛制积分权重和名次，系统自动完成将积分记入运动员及其代表学校的总分档案中。

### 3. 🔍 查询检索与统计排序模块
- **基础资料查询**：快速查阅所有参赛的系统基础资料及规则。
- **赛事成绩检索**：通过多重维度（按“竞赛项目名称”、按“参赛学校”、按“运动员姓名”）定向搜索所需成绩单。
- **统计排行榜生成**：以学校团体为单位降序排列，直观输出全校的 **总团体成绩**、**男子项目团体总分** 和 **女子项目团体总分**。

## 🛠️ 编译与运行指南 (Build & Run)

本项目使用 `CMake` 进行构建，确保你电脑配置了基本的 GCC/Clang/MSVC 编译链及 CMake 工具。

```bash
# 1. 确保将工程克隆或下载到了本地
cd SportsMetting_Manage_System_CPP

# 2. 创建并进入构建目录（外部构建，避免污染源码）
mkdir build 
cd build

# 3. 指定 CMake 配置文件进行项目构建（生成缓存）
cmake ..

# 4. 执行编译指令生成可执行文件
cmake --build .

# 5. 编译成功后，可执行程序会生成在根目录的 bin/ 文件夹下，双击或在终端中运行即可启动控制台菜单！
```
